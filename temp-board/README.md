# 두골비 임시 관리자

- 진입: `/temp-board/` 또는 `/temp-board/index.html`
- 목적: 업주가 교육·일정·프로모션·임상 결과·수료지점·게시판·사업정보를 한 화면에서 관리하는 흐름 검토.
- 홈페이지의 메인컬러와 Pretendard, 기존 로고·이미지를 사용한다. 복잡한 통계 대신 실제 콘텐츠와 자주 쓰는 작업을 우선한다.
- 공개 홈페이지와 운영 그누보드는 변경하지 않는다. 그누보드 원본을 이 폴더에 복제하지 않는다.

## 현재 구현

대시보드, 메뉴 이동, 검색/필터/페이지네이션, 등록/수정/삭제, 이미지 미리보기, 임시 이미지 선택, 사업정보 편집, 변경 기록, JSON 내보내기, 임시 데이터 초기화.

교육·일정·프로모션·수료지점·사업정보는 `../js/modify.js`에서 초기값을 읽는다. 임상 이미지는 작업 당시 실제 이미지 목록을 `seed.js`에 기록했다. 게시판은 **샘플 게시글**로 표시한다.

변경 내용은 `localStorage`의 `dugolbi-temp-board-v1`에만 저장한다. 업로드 이미지는 브라우저 저장 공간을 고려하여 파일당 최대 2MB로 제한한다. 실제 서버 파일 업로드나 홈페이지 게시가 아니다. 저장 실패 시 성공 메시지를 표시하지 않는다.

## 운영 연동 전 남은 작업

- 그누보드 5.6.40 로그인·관리권한 연결 및 실제 계정 검증
- 콘텐츠 저장 테이블과 이관, 실제 홈페이지 데이터 공급
- 게시판 쓰기/수정/삭제 토큰·권한·첨부파일 처리 연결
- 서버 이미지 업로드 검증과 저장, 실제 에디터 연결
- 이미지 변경/등록과 게시물 발행에 대한 운영 검수

이 페이지는 로그인 기능이 없는 시안이다. 운영 관리자로 배포하기 전에 위 작업이 필요하다.

## 검수 및 인수인계 (2026-10-07)

- PC 1440px, 태블릿 1024/768px, 모바일 375px에서 화면과 가로 넘침 확인.
- 등록·수정·삭제, 새로고침 후 임시 저장 유지, 검색, 페이지 이동, 이미지 선택 및 미리보기 확인.
- 모바일 메뉴 및 편집 바텀시트 확인. 검수 중 콘솔 오류 없음.
- 이미지 읽기 중 저장을 막아 이전 이미지가 저장되는 문제 보완.
- 검수용 브라우저 데이터는 초기화하여 홈페이지 원본 데이터로 돌려놓음.
- 다음 작업: 그누보드 로그인과 권한을 먼저 연결하고 콘텐츠 저장 및 게시판 작성·수정 연결. 운영 연동은 이번 시안 작업에서 수행하지 않음.
- 수정 파일: `css/common.css` (관리자 전용 범위), `router.php` (로컬 관리자 진입 경로). 기존 `modify.js` 및 그누보드 원본은 수정하지 않음. commit/push 하지 않음.
