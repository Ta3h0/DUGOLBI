# 두골비 임시 관리자

- 진입: `/temp-board/` 또는 `/temp-board/index.php` (`index.html`은 기존 주소 호환용). 비로그인 상태에서는 `login.php`로 이동.
- 현재 상태: 관리 화면과 브라우저 임시 편집 기능. 운영 홈페이지 게시 및 그누보드 저장은 아직 연결되지 않음.
- 기존 관리자 디자인·메뉴·모바일 바텀시트 및 홈페이지 스타일을 사용하며 새 프레임워크는 추가하지 않음.

## 현재 구현 (2026-10-14)

- 대시보드: 콘텐츠 개수, 빠른 등록, 변경 기록, 실제 다음 수업일 기준 예정 일정.
- 교육일정: 부산/서울 교육장, 기간 지정/요일 반복, 복수 요일, 선택적인 반복 시작·종료일, 수업 시작 시간, 색상, 예약 링크, 노출/숨김, 임시 일정 표시.
- 교육장별 목록 필터 및 교육장·요일·기간·시간 검색. 교육장을 바꾸면 기본 예약 URL도 변경하며 직접 입력한 URL은 유지.
- 이달의 교육: 교육명·기간·가격·소개·강조 문구·예약 주소·이미지 설명 및 커리큘럼 항목 추가/수정/삭제.
- 프로모션: 기존 제목·기간·이미지·본문 편집과 이미지 설명. 본문을 수정하지 않고 저장할 때 원래 문단 배열과 내부 줄바꿈 보존.
- 수료지점: 인증·연락처·수료자·이미지·상단 고정. 홈페이지와 같은 현판 호스팅 주소 변환 및 `cert/replace.jpg` 대체 이미지 사용. 본점 우선, 나머지 가나다순.
- 임상 결과: `seed.php`가 현재 이미지 폴더를 읽어 목록 생성. 공개 `results.html`과 `includes/results-data.php`의 같은 수집 함수를 사용. 고정 사본 `seed.js`는 제거.
- 공통: 검색/필터/페이지네이션, 등록/수정/삭제, 이미지 선택/미리보기, 변경 기록, JSON 내보내기, 임시 데이터 초기화.

## 독립 관리자 로그인 (2026-10-14)

- 지정 계정 `admin`으로 로그인. 비밀번호는 서버의 `auth-config.php`에 PHP 해시로만 저장하며 공개 HTML/JS에 넣지 않음.
- 그누보드 부트스트랩·계정·DB를 사용하지 않는 독립 PHP 세션. `auth.php`가 관리자 본문과 `seed.php` 접근을 검사.
- 세션 쿠키: HttpOnly / SameSite=Lax / 관리자 경로 제한, HTTPS 접속에서는 Secure 적용. 로그인 성공 시 세션 ID 및 요청 토큰 갱신.
- 미사용 2시간 또는 로그인 후 최대 8시간이 지나면 다시 로그인. 계정 설정 변경 시 기존 로그인도 무효화.
- 로그인/로그아웃 요청 토큰 검사, POST 로그아웃, 비로그인 직접 접근 차단 및 캐시 저장 방지. 같은 세션에서 5번 실패하면 60초간 재시도 제한. 서버 전체/IP별 제한은 아님.
- PHP 세션 저장 경로에 서버 쓰기 권한이 필요. 진입 파일은 `index.php`이며 Apache 디렉터리 기본 파일은 `.htaccess`에 지정.
- Edge 1440/375px에서 로그인·대시보드·로그아웃·뒤로가기와 가로 넘침/JS 오류 확인. HTTP 및 브라우저 검사 35건 통과(인증 실패, 요청 토큰, 직접 접근, 세션 ID 변경, 재시도 제한 포함).
- 이번 범위는 로그인만 서버에서 유지. 콘텐츠 저장은 아래 설명과 같이 여전히 브라우저 임시 저장이며 운영 배포는 하지 않음.

## 데이터와 저장 범위

교육·일정·프로모션·수료지점·사업정보의 초기값은 `../js/modify.js`에서 읽음. 임상 이미지는 현재 폴더 기준이며 게시판은 여전히 샘플 데이터임.

- 현재 임시 저장 키: `dugolbi-temp-board-v2`.
- 이전 `dugolbi-temp-board-v1`은 자동 적용하지 않으며 원본 키도 삭제하지 않음. 화면에서 이전 저장 내용을 JSON으로 내보낼 수 있음.
- v2 편집본의 기준 홈페이지 데이터가 바뀌면 안내 표시. 기존 편집본을 자동으로 버리지 않고, 내보내기 후 최신 원본으로 초기화할 수 있음.
- 저장 내용은 해당 브라우저에만 유지. `modify.js`, 실제 이미지 파일, 운영 DB에는 기록하지 않음.
- 이미지 선택은 JPG/PNG/WEBP/GIF, 파일당 2MB까지 임시 저장. 이미지 읽기 중 저장 차단 및 실제 픽셀 크기 반영. 서버 업로드 기능은 아님.
- 새로 선택한 이미지나 새 임상 항목은 관리자 임시 목록에만 추가됨. 실제 폴더 파일의 추가/삭제는 홈페이지와 관리자 초기 목록 모두에 반영됨.

## 검증 완료

- Edge 1440 / 1024 / 768 / 375px의 전체 메뉴 및 편집 화면, 가로 넘침 없음. PC/Mobile 화면 시각 확인.
- 기능 검증 17개 시나리오: 날짜 없는 반복 일정 저장, 요일/시간 유효성, 기간형 전환, 역전 기간 방지, 예약 URL 기본/사용자 지정 처리, 숨김 및 새로고침 유지, 본문 줄바꿈 보존, 커리큘럼, 이미지 픽셀 크기, 본점 우선 및 호스팅/대체 이미지, 텍스트 이스케이프, 이전 저장 분리 및 원본 변경 안내.
- 추가로 반복 기간 제한, 종료된 일정, 기간 내 해당 요일 없음, 진행 중 기간, 미래 일정의 예정 날짜 판정 확인.
- 공개 임상 수집 결과는 변경 전과 동일한 128개이며 경로·분류·원본 크기·순서 동일. 테스트 이미지 추가/삭제 반영 확인 후 테스트 파일 제거.
- JS/PHP 구문 검사 및 Git diff 공백 검사 통과. 새 JS 실행 오류 없음.
- 검수 데이터는 격리된 브라우저 저장에만 기록. 홈페이지의 프로모션 원고, 교육일정 4개 반, 이달의 교육 2026-10-01~2026-10-31 데이터는 변경하지 않음.

## 운영 연결에 필요한 환경과 미완료 작업

확인한 다운로드 원본은 그누보드 5.6.40. 현재 작업 프로젝트에 `/board/common.php` 및 `/board/data/dbconfig.php`가 없고, 제공된 다운로드 원본에서도 `data` 디렉터리가 제외되어 있음. 실제 관리자 세션·DB 연결을 이 로컬 환경에서 검증할 수 없음.

아래 항목은 구현 완료로 처리하지 않았음:

1. 기존 그누보드 계정·관리권한 연동 및 향후 서버 저장/삭제 요청의 권한/토큰 검사. 현재 독립 고정 계정 로그인은 완료.
2. 교육·일정·프로모션·수료지점·사업정보용 저장 테이블과 기존 데이터 이관, 홈페이지 데이터 공급 연결.
3. 서버 이미지 업로드 검증·저장·교체/삭제 처리.
4. 실제 공지사항·Q&A·리뷰·언론보도의 목록·쓰기·수정·삭제, 첨부파일 및 에디터 연결.
5. 운영 계정 및 실제 게시물 발행/수정 검수.

DB와 실제 운영 연결은 사용자 요청에 따라 보류. 추후 재개 시 운영과 호환되는 개발용 그누보드 설치본·DB 접속 환경·관리자 테스트 계정 연결이 필요. 민감한 설정을 공개 JS나 저장소에 넣지 않고 기존 그누보드 서버 설정과 세션을 재사용해야 함.
